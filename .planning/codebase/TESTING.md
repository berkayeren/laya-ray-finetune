# Testing Patterns

**Analysis Date:** 2026-10-13

## Test Framework

**Runner:**
- None. There is no test suite, no `tests/` directory, and no pytest/unittest config.

**Assertion Library:** Not applicable.

**Run Commands:**

```bash

# No automated tests. Verification is done by running the scripts (from CLAUDE.md):

laya-train --data data_neg8/train.jsonl --base multilingual --dry-run     # validate JSONL format
python ray_train.py --data data_neg8/train.jsonl --base multilingual --out ckpt \
    --workers 2 --freeze-encoder --max-messages 100 --epochs 2            # CPU training smoke test
python evaluate.py data_full/test.jsonl --checkpoint ./ckpt --workers 0 --n 20   # in-process eval, no Ray
```

## Test File Organization

**Location:** Not applicable. If tests are added, put them in a root `tests/` directory named `test_<script>.py`. The scripts live at the repo root and import siblings directly, so run pytest from the root.

## Test Structure

No suite. Substitute checks in use:
- **Smoke runs:** `--max-messages N` and `--freeze-encoder` in `ray_train.py` shrink training for CPU checks.
- **Subset eval:** `evaluate.py --n N` takes a subset after a seed-0 shuffle, so subsets are comparable across runs.
- **Ray-free debugging:** `evaluate.py --workers 0` runs `Predictor` in-process.
- **Format validation:** `laya-train --dry-run` checks the JSONL produced by `prepare_data.py`.

## Mocking

**Framework:** None. Nothing is mocked. Real Laya checkpoints (downloaded from `convaiinnovations/laya`) are used.

**Testable pure functions** (good unit-test targets, no Ray or model needed):
- `f1` and `metrics` in `evaluate.py` (take gold sets and prob dicts)
- `to_case` and `load` in `prepare_data.py` (take row dicts, a `random.Random`, and `neg`)

## Fixtures and Factories

**Test Data:** Generated by `prepare_data.py` from Multi3NLU++ (`DATA_DIR/turkish/banking fold0..19.json`) into `data_full/` and `data_neg8/`. These directories are not committed.

## Coverage

**Requirements:** None enforced. No coverage tooling.

Model quality is tracked through `results/*.json` reports (written by `evaluate.py --out`) and the README results table. These act as regression baselines. After changing the tag wording in `intents.py`, regenerate the data and re-run the baselines.

## Test Types

**Unit Tests:** None.
**Integration Tests:** Manual smoke runs only (above).
**E2E Tests:** Not used.

## Common Patterns

Gaps to know about when editing:
- `ray_train.py` depends on private `laya.train` APIs. Run the CPU smoke command above after any Laya upgrade.
- DDP invariants (equal-sized shards, identical calibration split across ranks) are untested. Verify with `--workers 2` after changing the sharding or calibration code.
- Ray workers need about 16 GB each. Smoke tests may run out of memory on small machines.
